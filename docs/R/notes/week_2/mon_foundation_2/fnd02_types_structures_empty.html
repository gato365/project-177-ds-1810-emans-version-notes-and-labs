0 · The one distinction, and your own chunks (8 min)

Type = what a single value is (number? text? TRUE/FALSE?). Structure = the container holding many values (vector? data frame? list?).

Everything today hangs off that sentence.

New skill today: you make the chunks. Last week every chunk was provided. From now on, when you see “➕ insert a chunk”, you create one yourself. Three ways — pick one and practice it until it’s automatic:

  1. Keyboard: Cmd + Shift + I (Mac) / Ctrl + Shift + I (Windows).
  2. Command Palette (Cmd/Ctrl + Shift + P) → type Quarto: Insert Code Cell.
  3. Type it by hand: a line with ```{r}, your code, then a line with ```.

YT0 (3 min). Directly below this line, insert a chunk. Inside it, write a comment # YT0 and the line 1 + 1. Run it. If output appears under your chunk, you’re ready.

2 · Data structures (30 min)

LM7 — vector: one type, many values (4 min). Built with c():

# LM7: a vector
drinks <- c("latte", "drip", "mocha")
drinks
[1] "latte" "drip"  "mocha"
length(drinks)
[1] 3
class(drinks)
[1] "character"

menu_tbl <- tibble(drink = drinks, price = c(4.75, 2.75, 5.25))

LM10 — list: the junk drawer (4 min). A list holds anything, even other structures:

$data
# A tibble: 3 × 2

3 mocha  5.25
length(my_list)
