3 · How big is data? (10 min)

LM9 — storage units (4 min). Data size is measured in bytes: byte → KB (thousand) → MB (million) → GB (billion) → TB (trillion). Rough anchors: this class’s survey ≈ a few KB · a semester of sensor logs ≈ MBs · a music library ≈ GBs · a national census extract ≈ TBs.

# LM9: how big are OUR objects?
object.size(airquality)
5632 bytes
object.size(iris)
7256 bytes
object.size(mtcars)
7208 bytes

Q5. Order the three from smallest to largest: ____

Why it matters: R holds data in memory. A 2 GB file on a 8 GB laptop imports; a 200 GB file does not — you’d need different tools. File size is the first thing to check before importing, which is exactly where next week begins.
