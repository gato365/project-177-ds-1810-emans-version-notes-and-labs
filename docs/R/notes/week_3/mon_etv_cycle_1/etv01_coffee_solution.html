0 · Context & ethics 8 min

ImportantTalking points (CLO 12.4)
  • Our data: 821 entries from a personal transaction ledger
  • Transaction logs can reveal routines, locations, and financial habits
  • Model sentence: “Someone might not expect a personal ledger to be used to infer their routine or financial situation.”

1 · The central question

How much do customers spend on coffee, and how does the amount spent vary?

  • description, account, month, year provide the available context

3 · T — Transformation 30 min

# LM3: select the relevant variables
coffee_small_df <- coffee_df |>
  select(description, amount, account, month, year)
# LM4: keep coffee purchases with recorded debits
coffee_clean_df <- coffee_small_df |>
  filter(str_detect(description, regex("coffee", ignore_case = TRUE)),
         !is.na(amount))

nrow(coffee_small_df) - nrow(coffee_clean_df)
[1] 77
NoteExpected — LM4
  • LM4 77 rows removed, leaving 744 coffee descriptions
  • Defense clause students should produce: “The description is our operational rule for identifying coffee, but it may miss or include some purchases.”
  • The negative sign is expected — the source is a transaction ledger
# LM5: convert ledger debits to positive spending
coffee_clean_df <- coffee_clean_df |>
  mutate(spending = -amount)
# LM6: center and spread
spending_summary_df <- coffee_clean_df |>
  summarize(
    mean_spending = mean(spending),
    sd_spending   = sd(spending),
    n             = n()
  )

spending_summary_df
NoteExpected — LM6
  • LM6 mean ≈ $5.95 · sd ≈ $5.45 · n = 744
  • The large spread is partly driven by unusually large ledger entries — interpret, don’t memorize

4 · V — Visualization & summary 20 min

# LM7: histogram of spending
ggplot(coffee_clean_df, aes(x = spending)) +
  geom_histogram(binwidth = 0.25, fill = "#12263A", color = "white") +
  labs(x = "Coffee spending ($)", y = "Purchases",
       title = "Coffee spending varies across ledger entries")
# LM8: geom_point — every purchase visible
ggplot(coffee_clean_df, aes(x = account, y = spending)) +
  geom_point(alpha = 0.5, color = "#12263A") +
  labs(x = "Account", y = "Coffee spending ($)",
       title = "Coffee spending by account — one point per purchase")

(Optional boxplot, if the class is ahead:)

ggplot(coffee_clean_df, aes(x = account, y = spending)) +
  geom_boxplot(fill = "#E3C36F") +
  labs(x = "Account", y = "Coffee spending ($)")
ImportantTeaching note — LM8
  • LM8 Points show the full transaction-level spread that the summary table compresses away
  • The account groups make the limits of the dataset visible: this is a ledger, not a random sample of all customers

5 · Interpretation & final answer 10 min

TipModel answer
  • “A typical recorded coffee purchase is about $5.95, with a standard deviation of roughly $5.45. The plot shows that the ledger contains many small purchases and a few much larger entries. We retained 744 of 821 rows whose descriptions contained ‘coffee’; that text rule is useful but not perfect.”
  • Required elements (the CLO 4.5 rubric for every cycle this term):
    • center — the mean
    • spread — the sd, in dollars
    • caveat — the filter rule
