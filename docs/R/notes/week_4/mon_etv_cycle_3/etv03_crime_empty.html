0 · Context & ethics (10 min)

Crime data are about people at some of the worst moments of their lives, and about neighborhoods that live with the numbers afterward. Before any code, discuss [instructor: keep 4–5]:

  • Privacy & confidentiality: [Can individuals — victims or accused — be identified from location, time, and offense together?]
  • Geographic stigmatization: [What happens to a neighborhood when its dot density becomes its reputation?]
  • Underreporting / inconsistent reporting: [Which offenses are least reported, and how does that bend every count we compute?]
  • Bias in policing or data collection: [Do these records measure crime, or measure enforcement?]
  • Responsible communication: [What must accompany a crime chart before it is shared outside this room?]

2 · E — Extraction (12 min)

LM1 — a new file type. This dataset arrives as an .RData file — an R object saved to disk. Unlike read_csv() or read_excel(), you don’t assign the result: load() places the saved object(s) directly into your environment.

library(tidyverse)

# LM1: load the .RData file
load("Data/[FILENAME].RData")

# What just appeared? List the environment:
ls()

LM2 — inspect. The loaded object is named [OBJECT_NAME].

# LM2: inspect

4 · V — Visualization & summary (20 min)

LM7 — the summary table. [Present crime_summary_df — this table should already half-answer the question.]

LM8 — geom_point(). [Plot the summarized counts as points — e.g., count by hour of day. Add honest labels; per the ethics discussion, the title must not overclaim.]

# LM8: ggplot(...) + geom_point()
ggplot(crime_summary_df, aes(x = [ ... ], y = n)) +
  geom_point(size = 3) +
  labs(
    x = "[ ... ]",
    y = "Number of reported incidents",
    title = "[Pattern, stated carefully — 'reported', not 'occurred']"
  )
